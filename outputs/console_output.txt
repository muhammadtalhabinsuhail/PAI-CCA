3. PREPROCESSING
==============================================================================
Steps applied:
  a) 'Unknown' / 'Patient Refused' -> missing value
  b) Spelling unified: 'ambulance' -> 'Ambulance', ED site codes -> 'Site A/B/C'
  c) Temperature converted from Fahrenheit to Celsius
  d) Impossible vital signs (e.g. heart rate > 250) -> missing value
  e) Rare chief complaints grouped into 'other' (kept top 30)
  f) Target created: admitted = 1 if disposition == 'Admit' else 0
  g) Missing numbers -> median + 'was missing' indicator; missing text -> 'Missing'
  h) Text columns -> one-hot encoding; numbers -> standard scaling
  i) Leakage check: ['home_medications'] kept for EDA but excluded from the model

Impossible vital-sign values set to missing: {'heart_rate': 1, 'systolic_bp': 0, 'diastolic_bp': 1, 'respiratory_rate': 6, 'oxygen_saturation': 0, 'temperature_c': 0}

5. CLASS IMBALANCE CHECK
==============================================================================
Admitted  : 29,801 (29.8%)
Discharged: 70,198 (70.2%)
Imbalance ratio: 2.36 discharged for every admitted patient
-> Moderate imbalance. A model that always says 'discharge' would already be
   70.2% accurate, so accuracy alone is misleading.
Handling: (1) stratified train/test split, (2) class_weight='balanced' so
   mistakes on admitted patients cost more, (3) metrics that focus on the
   minority class (recall, F1, PR-AUC), (4) decision-threshold tuning.
